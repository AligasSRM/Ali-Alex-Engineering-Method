# Communication Rules

**Status:** RED — communication policy drafted; team-specific workflow pending.

## Requirements
- Communicate verified facts, assumptions, uncertainty, and requested decisions separately.
- State impact, urgency, owner, and next action for material issues.
- Keep project decisions in the designated durable record rather than relying solely on chat.
- Use concise updates that include evidence and link to the source of truth.
- Report failed and skipped checks honestly.
- Avoid blame; focus on observable behavior, causes, and corrective action.
- Share only information recipients are authorized to access; redact secrets and unnecessary personal data.
- Escalate time-sensitive security, privacy, and release risks promptly.

## Status update format
**Current state → Evidence → Blocker/risk → Decision needed → Next action.**

## Acceptance evidence
A status update enables the recipient to understand the verified state and make the required decision without guessing.
